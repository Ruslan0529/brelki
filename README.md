# obscurium.lab — локальный прототип

Откройте `index.html` двойным щелчком. Сборка, npm и установка зависимостей не нужны. Шрифты подгружаются из Google Fonts при наличии интернета; без интернета используются системные шрифты.

Для просмотра через локальный сервер можно запустить из этой папки:

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

Затем открыть http://127.0.0.1:8080.

## Что работает

- Главная страница, адаптация для телефона и компьютера.
- Светлая и тёмная темы: выбор по настройке устройства и кнопка переключения в шапке. Ручной выбор сохраняется в браузере. Системная тёмная палитра доступна также без JavaScript.
- Иллюстрации изделий без чужих фотографий. Геометрия задаётся в SVG и выводится через Canvas, чтобы ночной режим браузера не перекрашивал отдельные детали мордочек.
- Выбор питомца, цвета шнура, сердечка, именной бусины и карабина.
- Предпросмотр, расчёт цены, готовые сочетания и сброс настроек.
- Сохранение настроек в браузере.
- Форма заявки, локальный просмотр до пяти фотографий и копирование текста заявки.

## Перед настоящим запуском

Бренд: obscurium.lab. Валюта — тенге (KZT). Базовая стоимость — 18 000 ₸. Примерные доплаты: сердечко — 2 000 ₸, именная бусина — 1 500 ₸. Коммерческие условия пока примерные. Вместо иллюстраций можно добавить фотографии своих работ.

Заявка сохраняется только в localStorage этого браузера, заменяя предыдущую заявку. Фотографии не загружаются на сервер и не сохраняются после закрытия страницы: в заявке остаются только названия файлов. При отправке текста мастеру фото нужно прикрепить отдельно.

Отправка заявки, онлайн-оплата, управление заказами и реальная доставка ещё не подключены.

## Файлы

- `index.html` — структура и текст страницы.
- `styles.css` — базовое оформление и мобильная версия.
- `brand.css` — фирменное оформление obscurium.lab.
- `theme.js` — определение темы до отображения страницы и переключатель.
- `art-canvas.js` — отрисовка геометрии наших иллюстраций и круглого логотипа через Canvas. Удалённые изображения и библиотеки не нужны.
- `assets/brand-mark.svg`, `assets/brand-seal-mobile.svg` — упрощённая векторная адаптация знака по присланному скриншоту; на круглом знаке буквы рисуются сплошным цветом, чтобы тонкие штрихи читались на телефоне.
- `app.js` — геометрия иллюстраций, конструктор и локальная заявка. Примерные цены находятся в функции `total()`.

## Обновления и Samsung Internet

При изменении CSS и JavaScript обновляйте параметр `v` в адресах ресурсов в `index.html`, чтобы браузер не использовал предыдущие файлы из кэша. Новый круглый знак имеет отдельное имя файла по той же причине.

Принудительная тёмная тема Samsung Internet может перекрашивать страницы поверх их собственной палитры. Для использования темы сайта Samsung рекомендует пункт «Use website dark theme» в Settings → Labs, если он доступен в установленной версии браузера: https://forum.developer.samsung.com/t/websites-dark-mode-gets-overridden-by-samsung-internets-dark-mode/22937/15.
